Редизайн kknow (десктоп, macOS, Markdown-заметки). Сохранить текущую визуальную базу: системный шрифт, светлый фон #f7f6f4 сайдбар / #fff редактор, акцент #2f6feb, радиусы 7–11px. 1. ШАПКА — только самое важное • Слева: светофор + переключатель хранилищ (цветная метка + имя + ⌄). • По центру: имя открытой заметки + серым путь до папки. • Справа: поиск (⌘K), новая заметка, тумблер «Превью». • Убрать из шапки: путь к папке, кнопку синхронизации, обновление, тему, язык. 2. СТАТУС-БАР СНИЗУ (высота 30px, 11.5px, цвет #6e6e73) • Слева: метка + имя активного хранилища, полный путь к файлу. • Справа: счётчик слов и время чтения; статус синхронизации активного хранилища (зелёная точка + «iCloud · 2 мин назад», при работе — спиннер и «3 из 8»); тема; язык; кнопка «Настройки» (⌘,). • Если в другом хранилище конфликт — красный чип «Архив 2024 · конфликт: 2 файла» с действием «Разобрать». • Все элементы статус-бара кликабельны: клик по синку = синхронизировать сейчас, по теме = переключить, по языку = меню, по пути = показать в Finder. 3. МНОЖЕСТВЕННЫЕ ХРАНИЛИЩА • Хранилище = папка + собственные настройки синхронизации, своя цветная метка, свои горячие клавиши ⌘1…⌘9. • Popover в шапке: список хранилищ с провайдером и временем последней синхронизации, статусные состояния: ok / идёт синк / выключена / конфликт. • Внизу popover: «Добавить хранилище…» и «Настройки хранилищ…». • Активное хранилище определяет дерево в сайдбаре, поиск и статус-бар. • Глобальный поиск по всем хранилищам — отдельный режим в ⌘K. 4. ОКНО НАСТРОЕК (⌘,) — отдельное окно, три колонки • Разделы: Общие, Внешний вид (тема), Хранилища, Клавиши, Редактор. Язык — в «Общие». • Раздел «Хранилища»: список слева (метка, имя, провайдер, индикатор состояния, кнопки + / − / ⋯), справа настройки выбранного: путь и «Показать в Finder»; провайдер (iCloud / Git / Dropbox / Локально); автосинхронизация; интервал; политика конфликтов; последняя синхронизация + кнопка «Синхронизировать»; статистика (заметок, папок, размер, горячая клавиша). 5. ПОВЕДЕНИЕ • Ничего из настроек не дублируется в главном окне, кроме быстрых переключений темы и языка в статус-баре. • Синхронизация идёт независимо по каждому хранилищу и не блокирует UI. • Ошибки и конфликты не показываются модалками — только чип в статус-баре.
